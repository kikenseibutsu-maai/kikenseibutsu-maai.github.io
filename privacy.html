プライバシーポリシー

対象: maai-uploader（YouTube チャンネル「危険生物の間合い」の動画投稿ツール）
最終更新日: 2026年11月11日

使う人

本ツールは、チャンネルの運営者が自分のチャンネルへ動画を投稿するためだけに使います。運営者以外の方の Google アカウントのデータは扱いません。

扱う Google ユーザーデータ

本ツールは YouTube API サービスを使い、運営者の YouTube アカウントについて次のことだけを行います。

  • 投稿先のチャンネルの名前と ID を確認する
  • 動画をアップロードし、タイトル、説明、公開日時を設定する
  • サムネイルを設定し、再生リストへ動画を追加する

保存と共有

Google から発行される許可の情報（アクセストークン、更新トークン）は、運営者のパソコンの中にだけ保存します。投稿した動画の記録も同じパソコンの中に保存します。これらのデータを販売せず、投稿の処理以外の目的で第三者に渡しません。

Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

許可の取り消しと削除

許可は Google アカウントの権限のページからいつでも取り消せます。運営者のパソコンに保存した許可の情報は、使わなくなった時点で削除します。

YouTube と Google のポリシー

本ツールは YouTube API サービスを使用しています。YouTube 利用規約と Google プライバシーポリシーもあわせてご確認ください。

お問い合わせ

YouTube チャンネルからご連絡ください。

English summary

maai-uploader is used only by the channel operator with their own account. It uses YouTube API Services to confirm the channel name and ID, upload videos, set metadata and thumbnails, and add videos to playlists. OAuth tokens and upload records are stored only on the operator's own computer. The data is not sold and is not shared with third parties except as needed to perform uploads through Google. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at Google Account permissions.
